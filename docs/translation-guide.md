# 翻譯指南

本專案的翻譯規則只寫在這裡；`scripts/terms.py` 與 `scripts/verify_mod.py` 會檢查其中能機器判斷的部分。

## 檔案

譯文在 `data/strings/*.tsv`，UTF-8、無 BOM、LF，以 Tab 分欄：

| 欄位 | 內容 |
|---|---|
| `en` | 遊戲畫面上的英文原文，逐字相同，包含開頭與結尾的空白 |
| `zh-Hant` | 台灣繁體中文 |
| `zh-Hans` | 中國大陸簡體中文 |
| `align` | 原文置中填 `c`、靠右填 `r`，靠左留空 |
| `note` | 出現位置、語境、決策理由 |

一個檔案放同一個畫面或同一類字串，檔名用英文小寫（`title.tsv`、`settings.tsv`）。

## 原文

- 原文從遊戲取得，不憑記憶打字：用 `dflang misses on` 記錄畫面上沒翻到的字串（見 skill `dflang-translate`），或從反編譯快照的 `exe/strings.tsv`、`raws_text.tsv` 複製。原因：引擎以位元組精確比對，差一個空白就不會命中。
- 遊戲把一句話拆成多段畫時，每段各自一條，前後空白跟原文一樣。例：`Range: `、數字、` to `、數字，譯成 `範圍：`、` 至 `，畫面上拼成「範圍：114 至 768」。
- 原文開頭的空白是縮排，譯文保留同樣數量的開頭空白。

## 繁簡分開翻

- 兩欄都要逐句自己翻：繁中依台灣用語，簡中依中國大陸用語。不用 OpenCC 或其他工具把一欄轉成另一欄。原因：轉換只換字形，換不了用詞（設定／设置、視窗／窗口、存檔／保存），也會把「預設」轉成大陸讀者不用的「预设」。
- 同一條的兩欄同時填或同時留空；只填一欄的條目建置時兩包會不一致，`verify_mod.py` 擋下。
- 兩岸常見差異列在 `glossary/locale.tsv`；`terms.py check` 會把 `level=error` 的誤用當 FAIL、`warn` 當提醒。
- 「列」兩岸意思相反：台灣「列」是橫的一排（row）、「欄」是直的（column）；大陸「行」是 row、「列」是 column。介面上的 bar 台灣用「列」（工具列、高度列），大陸用「栏」（工具栏、高度栏）。這類要看語境，`locale.tsv` 無法自動檢查。

## 術語

- 遊戲專有名詞與介面固定詞收在 `glossary/terms.tsv`，原文出現該英文詞（整詞，含複數）時，譯文要用表中譯名；同一詞有多個可接受譯名時以 `|` 分隔。
- 新術語由代理或譯者加成 `draft`；確認後改 `approved`。`approved` 不一致會讓 `terms.py check` 失敗，`draft` 只提醒。
- `approved` 會套用到所有字串，`category`、`note` 不會縮小範圍。遊戲裡另有別的意思的詞（例：`quit` 也用在性格描述 `Quits easily`，`range` 也是 `Archery range` 射箭場）維持 `draft`，在 `note` 寫出反例。
- 改譯名前先跑 `uv run scripts/terms.py impact <英文>`，列出所有受影響的句子一起改。

## 版面

- 譯文佔的格數不超過原文：CP437 字元（英數、半形標點）一格，中文字與全形標點兩格。超出時會蓋到旁邊的介面。
- 原文置中（按鈕、標題）時 `align` 填 `c`，引擎在譯文前補空白讓它落在同一中心；靠右填 `r`。
- 分頁標籤這類「上下兩列各寫一次、往下位移半格」的文字，中文只畫在上列，位置會比英文高半格，這是引擎目前的限制。

## 標點與用字

- 中文句子用全形標點：，。：；！？（）。繁中引號用「」『』，簡中用“”‘’。
- 數字、英文縮寫（FPS、ASCII）保留半形，與中文之間留一個半形空白（「畫面 FPS 上限」「預設 170」）；緊鄰全形標點時不加（「範圍：114」）。寬度不夠時可省略空白。
- 遊戲裡同一個英文詞在不同畫面意思不同時，在 `note` 寫明語境，不硬套術語表。

## 參考資料與署名

- 可以參考矮人要塞中文維基翻譯組的簡體中文資料（CC BY-NC 4.0）理解語境與既有譯名，但譯文逐句自己寫，不整句複製。
- 採用其譯名的術語，在 `glossary/terms.tsv` 的 `ref` 欄標 `dfzh-wiki`；整體致謝寫在 `CREDITS.md`。
- `translation-reference/` 只在本機（`scripts/lookup.py --refresh` 產生），不進 git、不放進工作坊包。
