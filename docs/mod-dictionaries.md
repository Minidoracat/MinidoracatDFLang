# 替其他模組寫中文字典

其他模組新增的生物、物品、材料名稱，本中文化的字典裡沒有，畫面上會照英文顯示。模組作者或玩家可以在那個模組裡放一份字典，裝了本中文化的玩家就會看到中文；沒裝的玩家不受影響。

## 放在哪裡

在模組的資料夾（有 `info.txt` 的那一層）底下加：

```
某個模組/
  info.txt
  objects/
  dflang/
    zh-Hant/strings.tsv    繁體中文
    zh-Hans/strings.tsv    簡體中文
```

兩種語言各一個檔，只寫一種也可以。模組從工作坊訂閱、或放在遊戲的 `mods` 資料夾都會讀到。加了或改了字典要重開遊戲才生效。

## 檔案格式

UTF-8 文字檔，一行一條，欄位用 Tab 隔開：

```
原文<Tab>譯文
```

- 原文要和遊戲畫出來的英文逐字相同，包含空白。名稱寫 raws 裡的小寫原文（`ice wolf`），遊戲把首字改成大寫時也找得到。
- 空行與 `#` 開頭的行會略過。
- 第三欄可以不寫；寫 `inner` 表示這一條只在別的句子裡當片段用，單獨畫出來時不翻。

例（`dflang/zh-Hant/strings.tsv`）：

```
# 冰原模組
ice wolf	冰原狼
ice wolves	冰原狼
ice wolf pup	幼冰原狼
frost iron	霜鐵
A wolf that lives on the glaciers.	棲息在冰河上的狼。
```

## 會怎麼顯示

- 名稱只要寫名詞本身。遊戲把名稱接成更長的字串時，中文化會把它接起來：寫了 `ice wolf` 與 `frost iron`，`ice wolf leather`、`frost iron battle axe`、`Stray ice wolf, ♀`、`rotten ice wolf meat [3]` 都會是中文。
- 單數、複數各寫一條（`ice wolf`、`ice wolves`），譯文通常相同。
- 生物說明（`DESCRIPTION`）一句寫一條，以句號分開。
- 同一句原文本中文化也有譯文時，用本中文化的：模組字典不能改掉原版的譯文。
- 字典用到本中文化字型沒有的字時，會用 Windows 內建的微軟正黑體（繁體）或微軟雅黑（簡體）補上。

## 檢查有沒有載入

遊戲開著時，在 DFHack 主控台看啟動訊息，每個模組字典有一行：

```
[DFLang] 模組 ice_mod 的字典：5 條（0 條原文無法比對、0 個字沒有字圖）
```

- 「原文無法比對」：那一條的原文有遊戲字型畫不出來的字元，檢查是不是貼到了全形字或特殊符號。
- 「沒有字圖」：譯文裡有字型都畫不出來的字。
- 檔案不是 UTF-8 時整個檔不載入，主控台會印紅字。

查某一句現在會翻成什麼：`dflang t "ice wolf leather"`。

## 目前不支援

模組字典只能寫整句與名稱。句型規則（含 `{1}` 佔位的樣板）與依畫面的譯文只有本中文化自己能寫：模組新增的反應名稱、互動訊息如果是遊戲拼出來的句子，要翻的話請到 GitHub 開 issue。
